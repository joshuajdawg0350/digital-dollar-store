How to use Text Toolbox

  1. Paste or type your text in the big box. Word, character, sentence, and line counts update as you type.
  2. Tap UPPERCASE, lowercase, Title Case, or Sentence case to change the whole text.
  3. Use “Remove duplicate lines” to delete repeated lines, keeping the first copy.
  4. Use “Sort lines A–Z” to put lines in alphabetical order.
  5. Use “Remove extra spaces” to collapse double spaces and tidy the text.
  6. For Find & Replace: type what to find, type the replacement, then tap “Replace all.”
  7. Tap “Copy result” to copy the finished text. Tap Undo if you need the previous version back.
