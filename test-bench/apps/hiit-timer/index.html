How to use Workout Timer

  1. Tap a preset, or type your own warm-up, work, and rest seconds and how many rounds.
  2. Tap Start and put the phone where you can see it. The numbers are made to read across a room.
  3. WORK means go. REST means recover. The word and color change each time.
  4. Listen for the beeps: short beeps count down, a long beep means switch.
  5. Use Pause to hold, Skip to jump to the next part, and Reset to start over.
