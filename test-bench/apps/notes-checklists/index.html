How to use Pocket Notes

  1. Tap + New Note to write a note, or + New Checklist for a list.
  2. Type a title and your words, then tap Save.
  3. For a checklist, add items and tap the box to check them off.
  4. Tap Pin to keep an item at the top.
  5. Use the search box to find any word in your notes.
  6. Tap Export on a note to download it as a text file.
