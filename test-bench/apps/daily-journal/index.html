How to use Daily Journal

  1. Today opens automatically. Read the prompt for an idea.
  2. Tap a face to pick today's mood.
  3. Write your entry and a gratitude line.
  4. Tap Save entry. It saves on this device only.
  5. Change the date at the top to read or edit a past day.
  6. Tap Export all to download every entry as a text file.
