How to use Tip & Split

  1. Type the bill amount at the top.
  2. Tap a tip percent — 10%, 15%, 18%, 20%, or 25% — or type your own in Custom tip %.
  3. If there was tax, type the tax amount. Leave it at 0 if tax is already in the bill.
  4. Use the − and + buttons to set how many people are splitting.
  5. Turn on “Round up” if you want each share rounded up to a whole dollar.
  6. Read the big number — that is what each person pays. The boxes below show the tip and totals.
