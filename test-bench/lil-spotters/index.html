🛡️ Safety & privacy — in plain words

  • Location is only used while the game is open. When a photo is snapped, the game saves where it was taken so it can pin it on the family map. The blue star shows this device's location only while the game is on screen.
  • Nothing is public. There are no accounts, no sign-ups, no strangers, no chat, no followers — nothing leaves this device except a parent link you choose to make and share.
  • Photos stay on this device. Finds and photos are stored in this browser on this phone. The parent link never carries photos.
  • No ads. Ever. No trackers, no data selling — that's the J-Dawgs promise on everything we make.
  • The PIN is a kid-lock, not a bank vault. It keeps little fingers out of the settings. If you forget it, erasing the app's data resets it (and the hunt).
  • Road safety: the game is for passengers. Drivers — eyes on the road; hunters ride in the back seat.

How to set up (passenger-seat edition)

  • 1. Pick the age tier above and a hunt deck.
  • 2. Say “yes” when the phone asks for camera and location — that's what lets finds land on the map. If you say no, the game still works: photos save without pins, and you can check finds off by hand in Finds.
  • 3. Hand the phone to your hunter. They tap a card when they spot the thing, then snap its picture.
  • 4. Open this Parent View any time (press-and-hold “Grown-ups”) to watch the treasure map fill in.
