## PART 4 — DELIVERY REALITY (what we can and cannot ship from our own website)

| Product | Deliverable from a website download? | How the buyer installs it |
|---|---|---|
| **Wallpaper (JPG/PNG)** | ✅ YES, trivially | Android & iPhone: save image → set as wallpaper. Zero friction. Ship 1440×3200 (Android) + 1290×2796 (iPhone) sizes. |
| **Wallpaper pack (ZIP of images)** | ✅ YES | Same as above, unzipped. This is the Etsy model. |
| **Icon pack — PNG files** | ✅ YES (Etsy model) | iPhone: apply each PNG via Shortcuts (the standard Etsy method, no jailbreak). Android: apply per-icon in Nova/Lawnchair/etc. or import. Works, but it's a 10–20 minute manual setup — the pack must include dead-simple picture instructions. |
| **Icon pack — installable APK** | ⚠️ POSSIBLE BUT FRICTION | An icon-pack APK sideloaded from a website works with Nova/Lawnchair/etc., but the buyer must enable "install unknown apps," dismiss Play Protect warnings, and gets no auto-updates. Trust-killing warnings on a $0.99 impulse buy. Prefer PNG delivery; APK is a later upgrade. |
| **Samsung full system theme** | ⛔ **NO — DO NOT DESIGN THIS** | Galaxy Themes content can only be built with Samsung's Galaxy Themes Studio, which requires passing Samsung's **designer portfolio review**; recruitment windows open roughly **once every two years** (last global window July 2023; qualification ran to Aug 2025; no new window announced in sources checked). Theme files cannot be installed from a website at all — Galaxy Store only. **Substitute:** wallpaper + icon sets that give Samsung owners the same look through the normal wallpaper/icon routes. |
| **Live (video) wallpaper** | ⚠️ PARTIAL | A raw MP4 can't be set as a live wallpaper on stock Android (needs an app wrapper APK — same sideload friction). Samsung Galaxy DOES let owners set a video as the **lock screen** from the Gallery app, so "video lock screen for Samsung" is shippable as an MP4 with instructions. iPhone Live Photo route is clunky. Keep this out of wave 1. |
| **Physical phone skin (vinyl wrap)** | ⛔ NOT A DOWNLOAD | A skin is a printed physical product — needs print/ship (print-on-demand partner) and per-model die cuts for hundreds of phone models. Not a $0.99 digital item. Out of scope for this line. |
| **Ringtone — Android** | ✅ YES, easy | MP3 download → Settings → Sound → Phone ringtone (or drop in the Ringtones folder). ~4 taps. Ship MP3 ≤30s. |
| **Ringtone — iPhone** | ⚠️ YES, WITH FRICTION | Apple does not let a web page install a tone. Working routes: (1) **iOS 26+:** save MP3/M4A (<30s) in Files → "Use as Ringtone" (reported in Oct 2026 tool reviews based on Apple docs — treat as **partially UNCHECKED** on real devices); (2) GarageBand import → Share → Ringtone (~8 steps, free, documented by Apple); (3) computer: drag the .M4R onto the iPhone in Finder/Apple Devices. **Every tone product must ship MP3 + M4R + a one-page picture guide**, and the listing must say "iPhone needs 2 extra steps" honestly. |

**Bottom line:** Wave 1 = wallpaper packs, PNG icon+wallpaper theme kits, and MP3/M4R tone packs. All shippable today from digitaldollarstore.org with a ZIP and an instruction card.
