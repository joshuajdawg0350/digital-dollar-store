ATS Resume + Cover Letter + References Bundle
=============================================

Start with Resume-Guide.docx — it explains which file to use where. Upload Resume-ATS.docx to job websites (it's built so applicant-tracking software can read it), email or print Resume-Designed.docx for humans, add Resume-Page-2-Extended.docx only if you have a long work history, and rewrite Cover-Letter.docx for each job using the four-paragraph pattern in the sample. References.docx holds three people who've agreed to vouch for you — ask them first. Every document is an EXAMPLE filled with a sample person: replace all of it with your own, in Word or Google Docs, and the PDFs are there to show you exactly what the finished pages should look like.
